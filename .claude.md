# FGA MCP Server & Skill - Project Context

## What This Project Is

An optimized MCP (Model Context Protocol) server and skill package for Fine-Grained Authorization (FGA) modeling with Claude Code. Provides expert guidance for both OpenFGA (self-hosted) and Auth0 FGA (hosted at dashboard.fga.dev).

## Recent Major Change: Chunked Prompts (March 2026)

**Problem:** MCP server returned ~11.1k tokens per query → "Large MCP response" warnings

**Solution:** Split monolithic file into 7 focused topic files

**Result:** 70-95% token reduction (now 0.6k-3.3k tokens per query)

## Architecture

### Two Components Working Together

1. **MCP Server** (Passive - Automatic)
   - Detects FGA patterns in queries
   - Injects relevant expert context
   - 80+ patterns across 7 topic areas
   - User never invokes directly

2. **Skill** (Active - Manual)
   - User invokes with `/fga <task>`
   - Provides structured workflows
   - Benefits from MCP's optimized context

### How They Collaborate

```
User: /fga design a document management model

↓ Skill: Loads workflow instructions
↓ Claude: Processes task, thinks about FGA concepts
↓ MCP: Detects patterns, injects relevant context (e.g., relationships.md)
↓ Claude: Generates model using skill workflow + MCP knowledge
```

## Content Strategy: OpenFGA vs Auth0 FGA

**Generic modeling concepts** (DSL, relationships, testing):
- Same for both OpenFGA and Auth0 FGA
- Go in generic files (intro, relationships, testing, etc.)

**Auth0 FGA-specific** (deployment, tooling):
- Different CLI commands, store management, SDK setup
- Goes in `fga-auth0.md`

Pattern matching routes correctly:
- "What is FGA?" → intro-concepts.md
- "How do I model hierarchies?" → relationships.md
- "How do I connect to Auth0 FGA?" → auth0.md
